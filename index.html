Live 24/7 Private Homelab

Homelab & Private Cloud Infrastructure

A self-hosted home server powered by Ubuntu Server and CasaOS, orchestrating 15+ containerized microservices. Built with a focus on data privacy, Zero-Trust remote connectivity, and local AI experimentation without relying on third-party cloud subscriptions.

Network & Security Architecture

Zero open router ports. Inbound traffic is strictly divided into two secure planes:

Private Administration Plane

Tailscale Mesh VPN

Peer-to-peer encrypted WireGuard tunnel allowing full, authenticated management access (CasaOS, Portainer, SSH, Vaultwarden) from any authorized device anywhere.

Edge Ingress Plane

Cloudflare Tunnel

Outbound-only daemon that proxies public web applications through Cloudflare's edge with automated SSL and DDoS mitigation, completely bypassing CGNAT without exposing my home IP.
